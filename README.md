# a-EMST

A program that implements Prim's algorithm to calculate the Euclidean Minimum Spanning Tree, with _alfa_ maximum distance between points, for a given set of points, where _alfa_ is an integer constant and the points have integer coordinates

## Input Format

See inputs/ folder for examples

## Usage
```
g++ a-EMST.cpp -o NameOfExecutable
./NameOfExecutable InputFile Alfa
```
